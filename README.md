The project was implemented as a Telegram bot to help users quickly find and retrieve correct answers during online tests and exams. The bot connects to a PostgreSQL database and allows fast searching across multiple question-answer tables, with priority given to a dedicated Exam table.
It was built using Python with aiogram 3.x for handling Telegram interactions asynchronously. Additional technologies include asyncpg for database access, pandas and openpyxl for generating Excel backups of all test data, and asyncio for managing real-time timers and exam sessions.
Key capabilities include an exam mode with a 60-minute limit and 40 attempts, automatic session control, payment confirmation flow with admin approval, live timer updates, and a clean menu system with inline and reply keyboards. The bot supports custom test numbering and provides a /backup command to export the full database.
The project is fully deployed on Railway using environment variables and a Procfile. It can also be compiled into a standalone .exe with PyInstaller for local use.
This solution demonstrates practical skills in asynchronous Python development, Telegram Bot API, database integration, real-time features, and cloud deployment.
